# Project Images

This folder contains all the screenshots and visual outputs used in the **HR Analytics - Employee Attrition Prediction** project.

## Contents

- **Correlation Heatmap** – Shows the correlation between numerical features.
- **Attrition Distribution** – Visualizes the distribution of employee attrition.
- **Feature Distribution Plots** – Displays the distribution of important employee attributes.
- **Confusion Matrix** – Evaluates the classification performance of the Logistic Regression model.
- **Feature Importance Plot** – Highlights the most influential features affecting employee attrition.
- **SHAP Summary Plot** – Explains the impact of each feature on model predictions using SHAP values.
- **SHAP Waterfall Plot** – Provides an explanation for an individual prediction.
- **Model Performance Graphs** – Additional evaluation and visualization charts generated during analysis.

## Purpose

These images are included to:
- Demonstrate exploratory data analysis (EDA).
- Visualize model evaluation metrics.
- Improve project documentation.
- Provide model interpretability through SHAP analysis.
